# UMLForge Mobile

Visor **de solo lectura** de diagramas UML para UMLForge (Expo + expo-router): login y registro, proyectos, visor de diagramas con zoom, historial de versiones, validación y diseño de datos, chat con la IA y notificaciones.

Guía de desarrollo en [`AGENTS.md`](./AGENTS.md).

```bash
pnpm install
cp .env.example .env     # EXPO_PUBLIC_API_URL=http://<IP-de-tu-PC>:8000
npx expo start
```
